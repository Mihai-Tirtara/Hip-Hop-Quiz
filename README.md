 🎵 Hip Hop Quiz App

## 📝 Description
A full-stack quiz application focused on hip-hop knowledge, built to enhance skills in modern web development technologies. The project is being developed in phases, progressively incorporating different technologies and frameworks.

## 🎯 Project Overview
This project is a learning journey through modern web development, starting with React and eventually incorporating Spring Boot, TypeScript, and Kotlin. The application allows users to test their hip-hop knowledge through an interactive quiz interface.
